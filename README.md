# Palms to Pixels – Virtual Whiteboard using Hand Gesture Recognition

This project is a virtual whiteboard application developed using Python, OpenCV, and computer vision techniques. It allows users to draw on a virtual canvas using real-time hand gesture recognition through a webcam.

## Features
- Real-time hand gesture detection
- Virtual drawing canvas
- Tool-free interaction using gestures
- Interactive and user-friendly interface

## Technologies Used
- Python
- OpenCV
- Computer Vision
