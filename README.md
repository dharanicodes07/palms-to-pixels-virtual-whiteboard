# Palms to Pixels – Virtual Whiteboard using Hand Gesture Recognition

Palms to Pixels is a computer vision-based virtual whiteboard application that enables users to draw on a digital canvas using real-time hand gestures captured through a webcam. This project eliminates the need for physical input devices such as a mouse, stylus, or touchscreen, providing a natural and interactive drawing experience.

The system uses hand tracking and gesture recognition to detect finger movements and convert them into digital brush strokes on a virtual canvas.

## Features

- Real-time hand gesture detection using webcam  
- Virtual drawing canvas with smooth brush strokes  
- Tool-free drawing using finger movements  
- Gesture-based interaction for intuitive control  
- User-friendly and interactive interface  
- Real-time processing with efficient performance  

## Technologies Used

- Python – Core programming language  
- OpenCV – Real-time image processing and computer vision  
- MediaPipe – Hand tracking and gesture detection  
- NumPy – Numerical processing and canvas operations  
- Webcam – Input device for gesture capture  

## How It Works

1. The webcam captures live video input  
2. MediaPipe detects and tracks hand landmarks  
3. Specific finger gestures are recognized  
4. The detected gestures are converted into drawing commands  
5. OpenCV renders the drawing on a virtual canvas in real time
